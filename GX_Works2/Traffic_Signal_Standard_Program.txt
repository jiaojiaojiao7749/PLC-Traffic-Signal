; GX Works2 FX3U 交通信号灯控制系统 - 标准梯形图程序
; ======================================================
; 项目名称: Traffic_Signal_Control
; PLC型号: FX3U
; 程序版本: 1.0
; 创建日期: 2026-10-05
;
; 输入定义:
; X0 - 启动按钮 (常开)
; X1 - 急停按钮 (常闭，按下时断开)
;
; 输出定义:
; Y0 - 南北红灯
; Y1 - 南北黄灯
; Y2 - 南北绿灯
; Y3 - 东西红灯
; Y4 - 东西黄灯
; Y5 - 东西绿灯
;
; 内部继电器:
; M0 - 系统启动标志
; M1 - 运行状态标志
; M2 - 南北绿灯状态
; M3 - 南北黄灯状态
; M4 - 东西绿灯状态
; M5 - 东西黄灯状态
;
; 定时器/计数器:
; T0 - 南北绿灯计时 (40秒)
; T1 - 南北黄灯计时 (5秒)
; T2 - 东西绿灯计时 (40秒)
; T3 - 东西黄灯计时 (5秒)
; ======================================================

ORG 0

;==================== 段 0: 启动和急停控制 ====================
; 功能: 系统启动/停止，急停处理
; =====================================================

M1101                      ; 初始化脉冲 (只执行一次)
SET M100                   ; 设置初始化完成标志
RST M0
RST M1
RST M2
RST M3
RST M4
RST M5
OUT Y0 Y5                  ; 初始化时所有输出关闭

; 紧急停止检测 (X1为常闭，按下时断开)
NOT X1
BRK                        ; 急停按下时跳过所有逻辑
RST M0
RST M1
RST M2
RST M3
RST M4
RST M5
OUT Y0 Y5                  ; 清除所有输出

; 启动按钮处理 (X0上升沿检测)
X0 AND NOT M0
SET M0                     ; 设置启动标志
SET M1                     ; 设置运行标志
SET M2                     ; 进入南北绿灯状态
RST M3
RST M4
RST M5

; 停止条件 (X0释放时停止)
NOT X0 AND M0
RST M0
RST M1
RST M2
RST M3
RST M4
RST M5
RST T0 K0                  ; 清除所有计时器
RST T1 K0
RST T2 K0
RST T3 K0
OUT Y0 Y5                  ; 清除所有输出

;==================== 段 1: 南北绿灯阶段 ====================
; 时间: 40秒
; 输出: Y2=亮, Y0 Y1 Y3 Y4 Y5=灭
; =====================================================

M1 AND M2 AND NOT M3 AND NOT M4 AND NOT M5

; 点亮南北绿灯
OUT Y2                     ; Y2=亮

; 清除其他输出
RST Y0                     ; 南北红=灭
RST Y1                     ; 南北黄=灭
RST Y3                     ; 东西红=灭
RST Y4                     ; 东西黄=灭
RST Y5                     ; 东西绿=灭

; 启动南北绿灯计时器 (40秒 = 400×0.1s)
TMXH K400 T0               ; T0计时40秒

; 计时完成后进入南北黄灯状态
T0 GE K400
RST M2                     ; 清除南北绿灯标志
SET M3                     ; 设置南北黄灯标志
RST T0 K0                  ; 清除计时器

;==================== 段 2: 南北黄灯阶段 ====================
; 时间: 5秒
; 输出: Y1=亮, Y0 Y2 Y3 Y4 Y5=灭
; =====================================================

M1 AND M3 AND NOT M2 AND NOT M4 AND NOT M5

; 点亮南北黄灯
OUT Y1                     ; Y1=亮

; 清除其他输出
RST Y0                     ; 南北红=灭
RST Y2                     ; 南北绿=灭
RST Y3                     ; 东西红=灭
RST Y4                     ; 东西黄=灭
RST Y5                     ; 东西绿=灭

; 启动南北黄灯计时器 (5秒 = 50×0.1s)
TMXH K50 T1                ; T1计时5秒

; 计时完成后进入东西绿灯状态
T1 GE K50
RST M3                     ; 清除南北黄灯标志
SET M4                     ; 设置东西绿灯标志
RST T1 K0                  ; 清除计时器

;==================== 段 3: 东西绿灯阶段 ====================
; 时间: 40秒
; 输出: Y5=亮, Y0 Y1 Y2 Y3 Y4=灭
; =====================================================

M1 AND M4 AND NOT M2 AND NOT M3 AND NOT M5

; 点亮东西绿灯
OUT Y5                     ; Y5=亮

; 清除其他输出
RST Y0                     ; 南北红=灭
RST Y1                     ; 南北黄=灭
RST Y2                     ; 南北绿=灭
RST Y3                     ; 东西红=灭
RST Y4                     ; 东西黄=灭

; 启动东西绿灯计时器 (40秒 = 400×0.1s)
TMXH K400 T2               ; T2计时40秒

; 计时完成后进入东西黄灯状态
T2 GE K400
RST M4                     ; 清除东西绿灯标志
SET M5                     ; 设置东西黄灯标志
RST T2 K0                  ; 清除计时器

;==================== 段 4: 东西黄灯阶段 ====================
; 时间: 5秒
; 输出: Y4=亮, Y0 Y1 Y2 Y3 Y5=灭
; =====================================================

M1 AND M5 AND NOT M2 AND NOT M3 AND NOT M4

; 点亮东西黄灯
OUT Y4                     ; Y4=亮

; 清除其他输出
RST Y0                     ; 南北红=灭
RST Y1                     ; 南北黄=灭
RST Y2                     ; 南北绿=灭
RST Y3                     ; 东西红=灭
RST Y5                     ; 东西绿=灭

; 启动东西黄灯计时器 (5秒 = 50×0.1s)
TMXH K50 T3                ; T3计时5秒

; 计时完成后回到南北绿灯状态
T3 GE K50
RST M5                     ; 清除东西黄灯标志
SET M2                     ; 设置南北绿灯标志
RST T3 K0                  ; 清除计时器

;==================== 段 5: 红灯亮度控制 (可选) ====================
; 说明: 红灯一般保持不亮
; 在实际应用中，红灯应与相应的绿/黄灯逻辑相反
; =====================================================

; 南北红灯逻辑 (南北绿/黄熄灭时亮起)
NOT M2 AND NOT M3 AND M1
OUT Y0                     ; Y0=南北红亮

; 东西红灯逻辑 (东西绿/黄熄灭时亮起)
NOT M4 AND NOT M5 AND M1
OUT Y3                     ; Y3=东西红亮

;==================== 段 6: 安全监视 ====================
; 功能: 定期检查系统状态
; =====================================================

; 防止多个状态同时激活 (容错)
M2 AND M3
RST M3                     ; 如果南北绿和黄同时亮，清除黄灯

M4 AND M5
RST M5                     ; 如果东西绿和黄同时亮，清除黄灯

END

;================================================================================
; 梯形图导入说明
;================================================================================
; 1. 在 GX Works2 中创建新项目，选择 FX3U 系列 PLC
; 2. 在"Program"选项中新建梯形图文件
; 3. 按照以下映射关系逐段输入梯形图:
;
; 段 0: 启动/急停控制
;   ├─ 初始化: M1101 SET M100; RST M0-M5; OUT Y0-Y5
;   ├─ 急停: NOT X1 BRK; RST M0-M5; OUT Y0-Y5
;   ├─ 启动: X0 AND NOT M0 SET M0; SET M1; SET M2
;   └─ 停止: NOT X0 AND M0 RST M0-M5; RST T0-T3; OUT Y0-Y5
;
; 段 1-4: 四个交通灯阶段
;   每段包含: 状态检测 -> 输出控制 -> 计时器 -> 状态转移
;
; 段 5: 红灯控制
;   南北红: NOT M2 AND NOT M3 AND M1 -> OUT Y0
;   东西红: NOT M4 AND NOT M5 AND M1 -> OUT Y3
;
; 段 6: 安全监视
;   防止状态冲突
;
;================================================================================
; 时间参数表
;================================================================================
; T0 (南北绿): K400 (40秒)  = 400 × 0.1秒/计数
; T1 (南北黄): K50  (5秒)   = 50 × 0.1秒/计数
; T2 (东西绿): K400 (40秒)  = 400 × 0.1秒/计数
; T3 (东西黄): K50  (5秒)   = 50 × 0.1秒/计数
;
; 若需修改时间，请修改 K 后的数值:
; 1秒 = K10, 5秒 = K50, 10秒 = K100, 40秒 = K400
;
;================================================================================
; 故障排查
;================================================================================
; 现象 1: 灯不亮
;   检查: X0是否按下，X1是否断开，输出接线是否正确
;
; 现象 2: 灯不切换
;   检查: 计时器是否正常工作，状态标志 M2-M5 是否正确设置
;
; 现象 3: 多个灯同时亮
;   检查: 段 6 的安全监视逻辑，确保状态互斥
;
; 现象 4: 急停无效
;   检查: X1 是否接成常闭（按下时断开），是否有硬件故障
;
;================================================================================
