[工程信息]
项目名称=PLC_Traffic_Signal_Control
PLC型号=FX3U
程序类型=梯形图
创建日期=2026-10-05

[IO配置]
输入=X0(启动按钮),X1(急停按钮)
输出=Y0(南北红灯),Y1(南北黄灯),Y2(南北绿灯),Y3(东西红灯),Y4(东西黄灯),Y5(东西绿灯)
内部继电器=M0,M1,M2,M3,M4,M5,M100
定时器=T0(南北绿40s),T1(南北黄5s),T2(东西绿40s),T3(东西黄5s)

【网络 0】初始化处理
────────────────────────────────────────────────────────────────────────────
┌─ M1101(初始化脉冲) ─ SET M100 ─ RST M0 ─ RST M1 ─ RST M2 ─ RST M3
└─ RST M4 ─ RST M5 ─ RST T0 ─ RST T1 ─ RST T2 ─ RST T3
└─ OUT Y0 Y1 Y2 Y3 Y4 Y5 (所有输出初始清零)

复制模板:
[梯形图逻辑]
|M1101| ─┬─ SET M100
         ├─ RST M0
         ├─ RST M1
         ├─ RST M2
         ├─ RST M3
         ├─ RST M4
         ├─ RST M5
         ├─ RST T0
         ├─ RST T1
         ├─ RST T2
         ├─ RST T3
         ├─[Y0]─
         ├─[Y1]─
         ├─[Y2]─
         ├─[Y3]─
         ├─[Y4]─
         └─[Y5]─

【网络 1】紧急停止处理
────────────────────────────────────────────────────────────────────────────
功能: X1 常闭，按下时断开，触发紧急停止
┌─ NOT X1 ─ BRK (跳过后续所有网络)
└─ 若进行紧急停止: RST M0 ─ RST M1 ─ RST M2-M5 ─ RST T0-T3 ─ OUT Y0-Y5

复制模板:
|/X1| ─┬─ BRK (中断执行)
        │
        └─当 X1 断开时:
          ├─ RST M0
          ├─ RST M1
          ├─ RST M2
          ├─ RST M3
          ├─ RST M4
          ├─ RST M5
          ├─ RST T0
          ├─ RST T1
          ├─ RST T2
          ├─ RST T3
          ├─[Y0]─
          ├─[Y1]─
          ├─[Y2]─
          ├─[Y3]─
          ├─[Y4]─
          └─[Y5]─

================================================================================

【网络 2】启动按钮检测 (X0上升沿)
────────────────────────────────────────────────────────────────────────────
功能: X0 按下且 M0 未设置时，进入运行模式
┌─ X0 ─ AND NOT M0 ─┬─ SET M0 (启动标志)
                     ├─ SET M1 (运行标志)
                     └─ SET M2 (进入南北绿灯状态)

复制模板:
| X0|/M0| ─┬─ SET M0
            ├─ SET M1
            ├─ SET M2
            ├─ RST M3
            ├─ RST M4
            └─ RST M5

================================================================================

【网络 3】停止条件检测 (X0释放)
────────────────────────────────────────────────────────────────────────────
功能: X0 释放时停止所有运行并清除所有输出
┌─ NOT X0 ─ AND M0 ─┬─ RST M0
                     ├─ RST M1
                     ├─ RST M2
                     ├─ RST M3
                     ├─ RST M4
                     ├─ RST M5
                     ├─ RST T0
                     ├─ RST T1
                     ├─ RST T2
                     ├─ RST T3
                     └─ OUT Y0-Y5 (全灭)

复制模板:
|/X0| M0| ─┬─ RST M0
            ├─ RST M1
            ├─ RST M2
            ├─ RST M3
            ├─ RST M4
            ├─ RST M5
            ├─ RST T0
            ├─ RST T1
            ├─ RST T2
            ├─ RST T3
            ├─[Y0]─
            ├─[Y1]─
            ├─[Y2]─
            ├─[Y3]─
            ├─[Y4]─
            └─[Y5]─

================================================================================

【网络 4】南北绿灯阶段 (40秒)
────────────────────────────────────────────────────────────────���───────────
条件: M1运行 AND M2南北绿状态 AND NOT M3 AND NOT M4 AND NOT M5
动作: Y2亮 + 其他灯灭 + 启动定时器T0(40秒)

复制模板:
| M1| M2|/M3|/M4|/M5| ─┬─ OUT Y2 (南北绿=亮)
                         ├─ RST Y0 (南北红=灭)
                         ├─ RST Y1 (南北黄=灭)
                         ├─ RST Y3 (东西红=灭)
                         ├─ RST Y4 (东西黄=灭)
                         ├─ RST Y5 (东西绿=灭)
                         └─[TMXH K400 T0]─ (定时器 40秒)

【网络 5】南北绿灯计时完成 → 转入南北黄灯
────────────────────────────────────────────────────────────────────────────
条件: T0 >= K400 (40秒到)
动作: RST M2 ─ SET M3 ─ RST T0

复制模板:
|T0 GE K400| ─┬─ RST M2 (清除南北绿)
              ├─ SET M3 (设置南北黄)
              └─ RST T0 (清除定时器)

================================================================================

【网络 6】南北黄灯阶段 (5秒)
────────────────────────────────────────────────────────────────────────────
条件: M1运行 AND M3南北黄状态 AND NOT M2 AND NOT M4 AND NOT M5
动作: Y1亮 + 其他灯灭 + 启动定时器T1(5秒)

复制模板:
| M1| M3|/M2|/M4|/M5| ─┬─ OUT Y1 (南北黄=亮)
                         ├─ RST Y0 (南北红=灭)
                         ├─ RST Y2 (南北绿=灭)
                         ├─ RST Y3 (东西红=灭)
                         ├─ RST Y4 (东西黄=灭)
                         ├─ RST Y5 (东西绿=灭)
                         └─[TMXH K50 T1]─ (定时器 5秒)

【网络 7】南北黄灯计时完成 → 转入东西绿灯
────────────────────────────────────────────────────────────────────────────
条件: T1 >= K50 (5秒到)
动作: RST M3 ─ SET M4 ─ RST T1

复制模板:
|T1 GE K50| ─┬─ RST M3 (清除南北黄)
             ├─ SET M4 (设置东西绿)
             └─ RST T1 (清除定时器)

================================================================================

【网络 8】东西绿灯阶段 (40秒)
────────────────────────────────────────────────────────────────────────────
条件: M1运行 AND M4东西绿状态 AND NOT M2 AND NOT M3 AND NOT M5
动作: Y5亮 + 其他灯灭 + 启动定时器T2(40秒)

复制模板:
| M1| M4|/M2|/M3|/M5| ─┬─ OUT Y5 (东西绿=亮)
                         ├─ RST Y0 (南北红=灭)
                         ├─ RST Y1 (南北黄=灭)
                         ├─ RST Y2 (南北绿=灭)
                         ├─ RST Y3 (东西红=灭)
                         ├─ RST Y4 (东西黄=灭)
                         └─[TMXH K400 T2]─ (定时器 40秒)

【网络 9】东西绿灯计时完成 → 转入东西黄灯
────────────────────────────────────────────────────────────────────────────
条件: T2 >= K400 (40秒到)
动作: RST M4 ─ SET M5 ─ RST T2

复制模板:
|T2 GE K400| ─┬─ RST M4 (清除东西绿)
              ├─ SET M5 (设置东西黄)
              └─ RST T2 (清除定时器)

================================================================================

【网络 10】东西黄灯阶段 (5秒)
────────────────────────────────────────────────────────────────────────────
条件: M1运行 AND M5东西黄状态 AND NOT M2 AND NOT M3 AND NOT M4
动作: Y4亮 + 其他灯灭 + 启动定时器T3(5秒)

复制模板:
| M1| M5|/M2|/M3|/M4| ─┬─ OUT Y4 (东西黄=亮)
                         ├─ RST Y0 (南北红=灭)
                         ├─ RST Y1 (南北黄=灭)
                         ├─ RST Y2 (南北绿=灭)
                         ├─ RST Y3 (东西红=灭)
                         ├─ RST Y5 (东西绿=灭)
                         └─[TMXH K50 T3]─ (定时器 5秒)

【网络 11】东西黄灯计时完成 → 回到南北绿灯 (循环)
────────────────────────────────────────────────────────────────────────────
条件: T3 >= K50 (5秒到)
动作: RST M5 ─ SET M2 ─ RST T3 (循环回到南北绿)

复制模板:
|T3 GE K50| ─┬─ RST M5 (清除东西黄)
             ├─ SET M2 (回到南北绿)
             └─ RST T3 (清除定时器)

================================================================================

【网络 12】南北红灯控制 (当南北绿/黄都不亮时，红灯亮)
────────────────────────────────────────────────────────────────────────────
条件: M1运行 AND NOT M2(非南北绿) AND NOT M3(非南北黄)
动作: Y0亮 (南北红灯)

复制模板:
| M1|/M2|/M3| ─┬─ OUT Y0 (南北红=亮)

================================================================================

【网络 13】东西红灯控制 (当东西绿/黄都不亮时，红灯亮)
────────────────────────────────────────────────────────────────────────────
条件: M1运行 AND NOT M4(非东西绿) AND NOT M5(非东西黄)
动作: Y3亮 (东西红灯)

复制模板:
| M1|/M4|/M5| ─┬─ OUT Y3 (东西红=亮)

================================================================================

【网络 14】容错保护 - 防止南北绿和黄同时亮
─────���──────────────────────────────────────────────────────────────────────
条件: M2 AND M3 (两个状态同时激活，不应该发生)
动作: RST M3 (清除黄灯标志)

复制模板:
| M2| M3| ─┬─ RST M3

================================================================================

【网络 15】容错保护 - 防止东西绿和黄同时亮
────────────────────────────────────────────────────────────────────────────
条件: M4 AND M5 (两个状态同时激活，不应该发生)
动作: RST M5 (清除黄灯标志)

复制模板:
| M4| M5| ─┬─ RST M5

================================================================================
                          程序总结
================================================================================

完整执行流程:
1. 初始化: 所有内部继电器和定时器清零
2. 启动: X0 按下 → M0=1, M1=1, M2=1 (进入南北绿灯)
3. 南北绿灯运行 40 秒 (T0 计时)
4. 南北黄灯运行 5 秒 (T1 计时)
5. 东西绿灯运行 40 秒 (T2 计时)
6. 东西黄灯运行 5 秒 (T3 计时)
7. 回到步骤 3，循环运行
8. 急停: X1 按下 (断开) → 所有输出清零，程序停止
9. 停止: X0 释放 → 所有状态清零，程序停止

================================================================================
                      变量对照表
================================================================================

输入变量:
  X0 = 启动按钮 (常开接点，按下时闭合)
  X1 = 急停按钮 (常闭接点，按下时断开)

输出变量:
  Y0 = 南北红灯
  Y1 = 南北黄灯
  Y2 = 南北绿灯
  Y3 = 东西红灯
  Y4 = 东西黄灯
  Y5 = 东西绿灯

内部继电器:
  M0  = 启动标志 (X0 按下时 SET，X0 释放时 RST)
  M1  = 运行状态标志 (系统运行时为 1)
  M2  = 南北绿灯状态标志
  M3  = 南北黄灯状态标志
  M4  = 东西绿灯状态标志
  M5  = 东西黄灯状态标志
  M100 = 初始化完成标志

定时器:
  T0  = 南北绿灯计时器，时间 K400 (40秒 @ 0.1秒/计数)
  T1  = 南北黄灯计时器，时间 K50  (5秒 @ 0.1秒/计数)
  T2  = 东西绿灯计时器，时间 K400 (40秒 @ 0.1秒/计数)
  T3  = 东西黄灯计时器，时间 K50  (5秒 @ 0.1秒/计数)

================================================================================
                      导入 GX Works2 的步骤
================================================================================

1. 打开 GX Works2 → 新建项目
2. 选择 PLC 型号: FX3U
3. 新建梯形图程序
4. 逐网输入以下内容:
   - 网络 0: 初始化
   - 网络 1: 紧急停止
   - 网络 2: 启动检测
   - 网络 3: 停止条件
   - 网络 4-5: 南北绿灯 (40秒)
   - 网络 6-7: 南北黄灯 (5秒)
   - 网络 8-9: 东西绿灯 (40秒)
   - 网络 10-11: 东西黄灯 (5秒)
   - 网络 12-13: 红灯控制
   - 网络 14-15: 容错保护

5. 检查所有输入输出是否正确映射
6. 编译 (Ctrl+F7)
7. 下载到 PLC (Ctrl+Shift+F5)
8. 开始运行

================================================================================
                      时间参数调整说明
================================================================================

如果需要修改时间，按以下公式修改:
  时间(秒) = K值 / 10

示例:
  K100 = 10秒
  K200 = 20秒
  K300 = 30秒
  K400 = 40秒 (默认南北/东西绿灯)
  K50  = 5秒  (默认南北/东西黄灯)

如需修改为其他时间，例如想要南北绿灯为 30 秒:
  原: TMXH K400 T0
  改: TMXH K300 T0
  原: T0 GE K400
  改: T0 GE K300
